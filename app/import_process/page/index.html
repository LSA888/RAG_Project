📚 掌柜智库

基于 RAG 的知识库智能问答系统
掌柜智库是一个本地知识库智能问答系统：把你的文档（PDF / Markdown）上传后， 系统会自动完成 文档解析 → 智能切分 → 向量化 → 入库， 之后你就可以用自然语言提问，系统会从知识库中检索最相关的内容， 结合大模型生成准确、可追溯的回答。
